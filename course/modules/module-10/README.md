## Module learning objectives

- Explain Stuxnet's targeting logic, propagation, and PLC-manipulation payload at the level supported by the Symantec dossier and Langner's published analysis.
- Explain WannaCry's exploitation vector (SMB), propagation worm component, and kill-switch, citing NCSC/NAO reporting.
- Explain NotPetya's initial-access vector, propagation (including credential-harvesting-assisted spread), and the wiper-vs-ransomware distinction, citing ESET/Microsoft reporting.
- Read a public APT campaign report and extract the actors' TTPs.
- Map each case study to specific MITRE ATT&CK technique IDs.
- Trace the path from a threat-intel report to actionable detection content (sets up Module 11).
