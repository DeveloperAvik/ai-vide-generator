# Module 1: Introduction to Malware & Exploitation

Non-technical/conceptual module. No lab-safety authorization is required to complete it (it's the module that introduces why that policy exists), but `LAB_SAFETY.md` should be read before Module 2.

## Module learning objectives

- Place any given malware family or exploit technique in historical context and in a standard classification scheme.
- Explain what distinguishes an APT from opportunistic malware.
- Map an attack narrative to both the Cyber Kill Chain and MITRE ATT&CK tactics/techniques.
- State, without hedging, the legal and ethical boundaries that govern every later module's labs.
