# Course-Wide Reference Index

Authoritative sources used across modules. Module-specific references also live in each `modules/module-NN/resources/`.

- MITRE ATT&CK — https://attack.mitre.org/
- MITRE CWE — https://cwe.mitre.org/
- NVD (CVE detail) — https://nvd.nist.gov/
- OWASP Top 10 — https://owasp.org/Top10/
- Lockheed Martin Cyber Kill Chain — https://www.lockheedmartin.com/en-us/capabilities/cyber/cyber-kill-chain.html

## Historical incidents (Module 10 primary sources)
- Stuxnet: Symantec "W32.Stuxnet Dossier" (Falliere, Murchu, Chien, 2011); Langner, "To Kill a Centrifuge" (2013).
- WannaCry: UK NCSC and NAO incident reports (2017–2018); MITRE ATT&CK S0366.
- NotPetya: ESET/Microsoft technical write-ups (2017); MITRE ATT&CK S0368.

## Practice targets referenced in labs
- Classic stack-overflow practice sets referenced in Module 7/8 labs are named explicitly in each lab README, drawn from long-standing public exploit-education resources (e.g., Exploit Education's "Phoenix"/"Protostar" successor material) rather than bespoke binaries.

All CVE numbers, version strings, and dated claims used in lesson content are cross-checked against the NVD entry or the vendor advisory before publication; a lesson under active drafting that has not yet been checked is flagged in that lesson's README under "Unverified claims" until verified.
