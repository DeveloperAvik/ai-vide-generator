# n8n automation

13 importable workflows in `workflows/` (generated by `generate_workflows.py`; regenerate after changes).
They call the Studio API with `Authorization: Bearer $STUDIO_SERVICE_TOKEN`. The service token can run pipeline stages but is **refused** by the approval endpoints: humans approve in the dashboard.

Required n8n environment variables (set in docker-compose already): `STUDIO_API_URL`, `STUDIO_SERVICE_TOKEN`, `N8N_BLOCK_ENV_ACCESS_IN_NODE=false`. Optional: `NOTIFY_WEBHOOK_URL`, `STUDIO_DASHBOARD_URL`.

Import: `docker compose exec n8n n8n import:workflow --separate --input=/workflows` (or UI: Workflows → Import from file).
Workflows ship inactive; activate the ones you want. Webhooks: `POST /webhook/studio/<path>` with `{"lesson_id": N}`.

| # | Trigger | Does |
|---|---|---|
| 01 | webhook `studio/course-generate` | generate curriculum |
| 02 | `studio/lesson-generate` | script stage |
| 03 | `studio/research` | research stage |
| 04/05/06 | `studio/voice`, `avatar`, `visuals` | asset parts |
| 07 | `studio/render` | render |
| 08 | `studio/quality` | quality checks |
| 09 | every 30 min | notify reviewers of pending approvals |
| 10 | `studio/youtube-upload` | private upload (API enforces APPROVED) |
| 11 | Mon/Wed/Fri 09:00 | upload next approved lesson, scheduled +48h |
| 12 | daily 06:00 | collect analytics |
| 13 | every 15 min | retry FAILED lessons from last good stage (max 3) |

Each webhook workflow: HTTP node with 3 retries → success response; error branch logs to `/api/internal/log`, optionally notifies, returns 502.
`credentials.example.json` documents optional n8n credentials; none are required.
